## Publisher contract (Application)

`INotificationPublisher` + `InAppNotificationPublisher` (Infrastructure). Callers own `SaveChanges`.

Pipeline:

1. Skip if recipient == actor (no self-notify).
2. Load `NotificationSetting` for `(user, type)` (missing → `CreateDefault` channel matrix, not persisted).
3. If in-app allowed → `Notification.Create` (no save).
4. If push allowed → `NotificationDeliveryOutbox.CreatePush` (same UoW; worker drains).
5. Email: deferred (settings flag ignored until provider).

Default channel matrix lives in `NotificationSetting.CreateDefault`.

### Notification language

Every notification type in the table above renders title/body from `NotificationsResource` (`src/Localization/Resources`) in the **recipient's** stored `User.PreferredLanguage` — never the ambient request culture, since a notification can be generated by a different actor than the recipient, or from a background job with no HTTP request at all (`EventReminderDispatcher`). `PreferredLanguage` is set at registration and kept in sync via `PUT /api/auth/me/language` (see [01-identity.md](01-identity.md)).

`NotificationActor` (`src/Application/Features/Notifications/NotificationActor.cs`) is the shared helper every producer uses:
- `ResolveUsernameAsync` / `FormatPrefix` — builds the "{actor} …" sentence prefix. Turkish keeps the historical "kullanıcısı" filler word (`"{username} kullanıcısı"`); English drops it. Falls back to `"Bir kullanıcı"` / `"A user"` when the actor has no profile.
- `ResolveRecipientLanguageAsync` / `ResolveRecipientLanguagesAsync` — single- and batch-recipient language lookups, so a fan-out notification (event cancellation, event invitation, a chat message to a group) issues one query instead of N and renders each recipient's copy in *their own* language within the same call.
- `Format(language, resourceKey, args)` — resolves a `NotificationsResource` template for an explicit language and formats it.

Dynamic content (a chat message's text, a comment/reply preview) is never translated — only the static shell text (title, and any body text that isn't user-authored) goes through this pattern.
